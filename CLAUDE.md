# CLAUDE.md

Guidance for working in this repo.

## What this is

`ergodic` is a Causal AI library (from ergodic.ai), published on PyPI as `ergodic`. Four pillars: causal discovery, causal inference, process intelligence, and forecasting. They all sit on two shared objects, which are built first.

## Core objects (built)

- `ergodic.graph`: a mixed-graph family. One `MixedGraph` core with typed endpoint marks (tail, arrowhead, circle) covers DAG, ADMG, MAG, CPDAG, and PAG. Build with `dag`, `admg`, `cpdag`, `pag`, or `mixed`. Edges read as glyph strings, e.g. `dag(["X -> Y", "Y -> Z"])`. Graphs are immutable value objects: every edit returns a new graph (`set_mark` edits one endpoint). One edge per node pair: conflicting duplicates raise, so a bow is written as an explicit latent confounder (`latent=`). Separation (`m_separated`, `d_separated`) validates node names and reads circle marks through Zhang's definite-status paths (class-invariant on a complete PAG); a CPDAG-kind graph gets the same class reading (undirected edges recode as circles; a mixed-kind graph walks tails literally); surgery (`do`, subgraphs) and interop (networkx, adjacency, dict) live here; the dict is versioned (`to_dict` writes `"format": GRAPH_FORMAT`, i.e. `"ergodic.graph/1"`; `from_dict` reads a missing field as version 1 and refuses any other). The class machinery is public and the validators are real: Meek + Dor-Tarsi (`meek_closure`, `cpdag_of_dag`, `consistent_extension`) make `is_cpdag` complete (with an `ambiguous=` triple gate on R1/R3 for the conservative-PC family), and the PAG toolkit (`graph/_pag`: `mag_of_dag` projection, `pag_of_mag` canonical PAG, `mag_of_pag` member extraction by arrowhead augmentation, `fci_closure` with Zhang's complete ten rules) makes `is_pag` complete by round trip. Selection bias is in scope end to end: `is_mag` checks the Richardson-Spirtes ancestral conditions (undirected endpoints carry no arrowheads), `mag_of_dag` projects `latent=` and `selection=` together (tail iff ancestor of the other end or of selection; the witness set conditions on S), R5-R7 are the selection rules, and the executable contracts are RS Thm 4.18 (MAG m-separation == DAG d-separation given Z union S) plus round trips over random selection worlds. Class reachability and certificates ride along: `possible_descendants`/`possible_ancestors` (possibly directed reachability, equals union-over-members in tests), `visible_edges` (Zhang's no-hidden-confounding certificate), and the member enumerators `dags_of_cpdag` (branch + Meek-close, every leaf verified by `cpdag_of_dag`) and `mags_of_pag` (circle assignments filtered by `is_mag` + `pag_of_mag` round trip; `selection=False` default lists the selection-free members and raises on selection-marked PAGs, `True` widens to the full Markov class), both deterministic with a `max_members` cap that raises. Identification raises on selection marks (the generalized adjustment criterion assumes none).
- `ergodic.knowledge`: `DomainKnowledge`, prior constraints (required/forbidden edges, tiers, roots, sinks, confounded pairs). Immutable, composable with `&`, self-checking via `conflicts`/`validate`, with projections (`permits_edge`, `is_consistent`, `apply_to`, `edge_mask`) for discovery to read. Adjacency bans cover every edge type and precedence is transitively closed. Every builder but `confound` takes `confidence=` (DEC-081): `None`/1 is the hard constraint stored as before, `[0.5, 1)` a soft `KnowledgeStatement` in `soft`, read pair by pair as a likelihood ratio on each directed state (`log_odds`, `log_prior`, `energy`); the hard projections ignore soft statements, the searches and `bootstrap` refuse them (`knowledge.hard()` drops them), and soft order is not transitive. `forbid_adjacency` also records `nonadjacent` (bans `<->` too); two directed forbids plus `confound` mean confounded-but-not-causal. `decode` weighs soft statements on the pair states, turns `confound` into an ADMG (a bow as an explicit `L__a__b` latent), and audits every statement against the model (`audit=False` skips it; `KnowledgeConflictWarning`).
- `ergodic.identification`: graph to estimand. `identify_effect(graph, X, Y)` tries adjustment (the complete criterion), front-door, instruments, then the general do-calculus ID algorithm, and returns an `Identification` record with the estimand. Also `adjustment_set`, `minimal_adjustment_set`, `frontdoor_set`, `instruments`, and their `is_*` checks. Graph-only and deterministic. The graph's face dispatches: DAG/ADMG reason about one world; CPDAG/MAG/PAG run the generalized adjustment criterion (Perkovic 2018: amenability via visible first edges, possible-ancestry forbidden set, definite-status blocking in the proper back-door graph), so a success holds in every member of the class, held executably to all-members enumeration in `test_identification_classes.py`. Class null = no possibly causal path in any member; front-door/instruments raise on a class with a pointer at the enumerators (the IDA pattern); mixed kinds raise. Latent nodes are excluded from every returned set, inputs are validated, instruments are never descendants of the treatment (IV identification is linear/parametric and says so), and a graph with no directed path from treatment to outcome identifies as the zero-effect `"null"` strategy. The general do-calculus ID algorithm (Shpitser-Pearl ID + IDC, `identification/_id.py`) is the single-graph fallthrough: it decides every identifiable case and returns a typed `Functional` estimand (`Prob`/`Product`/`Marginal`/`Ratio`, public-but-provisional, with `render`/`free_vars`/`simplify` and a reusable discrete evaluator), or a `Hedge` witness when none exists. `identify_distribution(graph, outcome, do, given=)` is the raw entry (IDC when `given` is set, empty `do` allowed as the observational query); `identify_effect` runs it after the named ladder and reports `strategy="id"` with the functional unless it recognizes a named form, held to a soundness-against-truth anchor plus an independent Tian-Pearl oracle (~33k queries, zero disagreements). `ida(graph, X, Y)` identifies across a CPDAG's members (the IDA multiset; PAG/MAG members need a DAG realization and are deferred). The discrete plug-in estimates a general `strategy="id"` functional from data through `estimate_effect` (discrete/binary/positivity guards; a continuous functional raises and points at the SCM). Mediation: `identify_mediation` decides NDE/NIE (three back-door conditions, the untestable cross-world assumption stated in words) and CDE (a plain interventional contrast that can identify when the naturals do not); `estimate_mediation` is the g-computation estimator returning a `MediationEstimate` (NDE/NIE/total/CDE, proportion mediated). `latent_projection` (`graph/_primitives.py`) builds the ADMG the engine reads; a bow is two parallel edges internally, and `to_dict`/`to_adjacency`/`to_networkx` raise on one rather than mangle it.
- `ergodic.data`: the typed datasets the algorithms read. One `Dataset` base carries a column `Schema` (continuous, categorical, ordinal, datetime, excluded; binary is derived) across five shapes: `TabularData`, `TimeSeriesData`, `PanelData`, `HierarchicalTSData` (with a `Hierarchy` aggregation tree), and `EventLog`. Build with `tabular`, `timeseries`, `panel`, `hts`, `event_log`. Immutable; a dataframe builds it and stays at the boundary (`data/_frame.py`), the math runs in numpy. Accessors: `variables`, `codes`, `matrix`, `dropna`, `select`, `aligns_with(graph)`. Containers only; the per-shape algorithms ride with their pillars.
- `ergodic.inference`: estimation (E1 + E2 built, plus Bayesian learners). `estimate_effect(graph, data, X, Y)` identifies the effect then estimates it, returning a distribution-shaped `EffectEstimate` (a point with an analytic or bootstrap standard error, or draws). A `CausalEstimator` is the strategy and a `Learner` is the model in each nuisance slot; the `Learner` is structurally a sklearn estimator, so any sklearn or xgboost model drops in. Adjustment: `OutcomeRegression` (S/T-learner), `IPW`, `Stratification`, `AIPW`, and the cross-fit `DML`, `DRLearner`, `RLearner`, `XLearner`. Front-door: `TwoStageRegression`. Instruments: `TwoStageLeastSquares`, `Wald`, `PLIV`. Heterogeneous effects through `cate(data)` on the CATE estimators (a shared `_MetaLearnerBase` factors the pseudo-outcome -> second-stage-regression -> per-unit-prediction pattern; the DR/R/X/S/T math is unchanged) and the top-level `cate(graph, data, X, Y, *, method="auto", learner=None)` facade, identification-gated exactly like `estimate_effect` (DR-learner default; `DML.cate()` is the constant homogeneous case; neural/foundation method names are a reserved `ergodic[neural]`/`ergodic[foundation]` seam that raises NotImplemented). Every `cate()` returns a uniform `CATEResult` (a `PerUnitEffect` sibling of `EffectEstimate`, NOT a subclass: `.values`/`__array__`/`.interval(level)`/`.std_error`/`.draws()`/`.ate() -> EffectEstimate`/`.to_frame()`, drop-in array-like so old `np.mean(cate())` callers still work) carrying per-unit uncertainty (a Bayesian slot's posterior draws, the bootstrap otherwise, the DR analytic IF when the final stage is linear; `cate(..., uncertainty=False)`/`.cate(uncertainty=False)` skips it for a fast point-only `kind="point"` result, the per-unit points being identical), the `Identification`, and cached cross-fit doubly-robust scores. `CATEResult.explain() -> Heterogeneity` runs the Tier-B characterization off those scores with honest CIs and an out-of-fold proxy ranking (the literature's honesty recipe): `.blp()` (best linear projection on covariates, HC3), `.gates(n_groups=5)` (sorted group ATEs + top-minus-bottom contrast), `.clan()` (who is in the high-effect group), `.calibration_test()` (the grf omnibus HTE test), `.rate(metric="autoc"|"qini")` (rank-weighted ATE, half-sample-bootstrap SE). The shared `dr_scores(identification, data, ...)` is the one orthogonal AIPW object both the estimators and the explainability layer read. Phase 2 adds three native pieces: a `CausalForest` (`method="causal_forest"`/`"grf"`, GRF honest sample-splitting, a forest-kernel local-moment readout, infinitesimal-jackknife per-unit CIs as `kind="analytic"` where the others bootstrap, and depth-weighted `variable_importance()`); interpretable policy learning (`policy_tree`/`CATEResult.explain().policy_tree(depth=)` -> a `PolicyTree`, the depth-<=2 DR-welfare-optimal treat-or-not rule with policy value and regret, the act companion to `rate`); and CATE model selection (`select_cate` -> a `SelectionReport`, doubly-robust tau-risk ranking over candidate learners plus a Q-aggregation convex ensemble). `SCM.ite(...)` returns an `ITEResult` (the same `PerUnitEffect` surface, factual column + levels/shift framing + a structural note; `.explain()` deferred with a pointer). Binary treatment for most, binary or continuous for `DML` and `PLIV`; `treated=` picks the treated level of a non-numeric treatment (implicit coding warns), and the zero-effect `"null"` family lands in `NullEffect`. Native `OLS`, `LogisticRegression`, and `KNN` learners keep it dependency-free. A `BayesianLearner` carries a posterior over its mean (detected by `predict_draws`); a `PyMCLearner` wraps a user-written PyMC model (pymc optional, imported inside the methods). `OutcomeRegression` (g-formula) and `AIPW` (doubly robust, with a Dirichlet Bayesian bootstrap on by default) then return a posterior `EffectEstimate` (`kind="posterior"`) through the same accessors, and the T-learner gives per-unit CATE credible intervals via `cate_draws`/`cate_interval`. A Bayesian slot never bootstraps (that would refit the sampler); with no posterior path it falls back to the analytic or point result. The quasi-experimental designs sit beside the graph path: `did`/`event_study` over `PanelData` (canonical two-period collapse for one adoption date, Callaway-Sant'Anna group-time ATTs for staggered; `comparison="never_treated"|"not_yet_treated"`; static TWFE offered with its Goodman-Bacon caveat, never auto-picked; unit-bootstrap inference; e=-1 is the omitted reference), `synthetic_control` (one treated unit, simplex weights by projected gradient on the pre-period, Abadie placebo rank p, `interval()` is a placebo band and `std_error` stays None), and `interrupted_time_series` over `TimeSeriesData` (segmented regression, level+slope changes, Fourier seasonality, Newey-West SEs). Each returns an `EffectEstimate` subclass (`DiDEffect`, `SyntheticControlEffect`, `ITSEffect`) carrying a `Design` record (the identification claim in words: parallel trends, convex donor span, continuing trend) instead of an `Identification`.

- `ergodic.discovery`: structure learning (D1 + D2 + D3 + D4 built). Two ingredient objects. A `CITest` is a class constructed with data (the stateful oracle: encoding per the test's declared form, cached alpha-independent queries): `Linear`, `Discrete`, `Mixed`, `GCM` (any regression `Learner` in the slots, in-sample residual product, catches nonlinear dependence), plus `DSeparationOracle` as ground truth (answers about the observed margin; latents and selection are not query-able, and every query conditions on `graph.selection`). A decomposable `Score` answers `local(node, parents)` in two declared forms (`local_from_arrays` numeric, `local_from_codes` native categorical): `BIC` (Gaussian), `DiscreteBIC`, `BDeu`, `MixedBIC` (degenerate Gaussian, reduces exactly to `BIC` on single-column nodes); all decomposable and score-equivalent, tested executably. Algorithms are thin consumers declaring `ingredient` ("test", "score", or None when the machinery is the algorithm): `PC` (stable skeleton, v-structures, Meek closure, CPDAG with sepsets; `colliders="conservative"|"majority"` votes each unshielded triple over both neighborhoods' deduped subsets, ambiguous triples are never oriented and gate Meek R1/R3, honest face with `n_ambiguous_triples`), `FCI` (the shared stable skeleton, possible-d-sep re-test, circle v-structures, `fci_closure` with the complete ten rules; PAG out, held executably to `pag_of_mag(mag_of_dag(truth))` under the oracle on random latent DAGs, ADMGs, and latent+selection worlds; knowledge via ancestry: tiers pin an arrowhead at the later end, `confound` orients `<->`, required orients fully, directional forbids/roots/sinks validate only; knowledge-seeded outputs drop to the mixed face with `pag_valid=0.0`), `RFCI` (skips possible-d-sep; Lemma 3.1 triple re-tests with edge removals and minimal sepsets, Lemma 3.2 path tests inside the R4 callback with deletion-restart; RFCI-PAG out: skeleton a supergraph of FCI's, every shown mark sound against the true MAG, both held executably; equals FCI wherever pds has nothing to do), and `MMPC` (max-min parents-children screen, AND rule, undirected skeleton for `restrict_to`; MMHC = MMPC + a score search as a composition) wrap a test; `GES` (Chickering two-phase, CPDAG out, held to the A* optimum in tests), `HillClimb` (steepest ascent with a tabu ring, best-seen state), `AStar` (exact, order lattice, node cap), and the order-based `BOSS` (grow-shrink projection of a permutation, best-move sweeps, BES via GES's backward phase, held to the A* optimum) and `GRaSP` (tuck DFS over the same projection, also held to A*; tucks only move existing edges so prefer BOSS under heavy knowledge) wrap a score, resolved at fit (`score="auto"` reads the schema like `test="auto"`). No-ingredient methods: `DirectLiNGAM` (`method="lingam"`: maxent pairwise likelihood ratio picks the most exogenous variable, residual recursion, backward-BIC pruning on original data; full DAG out, continuous non-Gaussian only, Gaussian documented unidentifiable; knowledge gates roots via tiers and acts at pruning, a required edge against the found order raises) and `Glasso` (`method="glasso"`: FHT block coordinate descent on the correlation matrix matching sklearn entry for entry, EBIC gamma=0.5 at the support-restricted refit MLE over a warm-started 100-point path, per-entry penalties carry knowledge, undirected mixed face for `restrict_to`). `discover(data, method=...)` is the facade; `bootstrap(data, method=..., n_bootstrap=...)` reruns any method on resamples and returns adjacency/glyph frequencies with a thresholded `summary()` (the first soft output; not posteriors): iid rows via `Dataset.take`, a `TimeSeriesData` via moving blocks that become entities of a panel (no lag window crosses a block seam; `block_length` defaults to ~sqrt(T) floored to out-span `max_lag`), a `PanelData` via whole-entity cluster resampling. Knowledge enters in four modes (prune, protect, orient, validate); `DomainKnowledge.restrict_to(skeleton)` confines any search to an adjacency support (a pruned pair records no sepset, so PC-inside-a-screen orients less; score searches lose nothing). Temporal discovery (D-TS): `discover(data, method="pcmci", max_lag=...)` reads `TimeSeriesData` or `PanelData` (windows pooled within entities) through `lagged_tabular` (so any `CITest` and `test="auto"` work unchanged) and returns a `TimeSeriesDiscoveryResult`: a window graph over `X[t-1]`-style nodes (dag kind when fully oriented, mixed otherwise), per-link p-values in `links[(src, dst, lag)]`, `summary_edges()` at the variable level (no summary graph on purpose: cross-lag feedback is normal and one-edge-per-pair is not bent for it). PCMCI shape: PC1 lagged screen, MCI tests conditioned via a 2x-deep lagged frame (truncation falls back with a diagnostic), PC-stable contemporaneous phase conditioned on lagged parents, collider + within-slice Meek R1/R2 (conflicts stay undirected and are counted). Knowledge on PCMCI reads variables as processes: forbids/tiers/roots/sinks prune links at every lag (self-memory survives roots and sinks), tiers orient contemporaneous edges earlier to later, `require` validates after the run (no surviving lag raises), `confound` raises, `n_knowledge_pruned` counts. `granger` returns a pair-level table, not a graph (predictive, confounding-blind, the docstring says so). Guards: iid methods reject temporal shapes inside `resolve_test`/`resolve_score` (so direct class use is covered), no-ingredient methods guard their own shapes, `pcmci` rejects tabular.

- `ergodic.process`: process intelligence over an `EventLog` (P1 + P2 + P3 built). Descriptive layer: `process_map` (the DFG as a frozen value object, START/END boundary arcs, gap stats in seconds, `simplify(keep=)` records `dropped_arcs`/`dropped_share` and accumulates; deliberately NOT a MixedGraph, A->B and B->A both happen), `performance` (cycle times; waiting/service split only when `lifecycle=` names a column with start/complete pairs, `n_unmatched` counted; complete-only logs honestly cannot split), `variant_table`, and six filters (time with contained/intersecting/trim, variants, endpoints, activities with keep/mandatory/forbidden, follows with within=, performance), each docstring leading with "Drops cases:" or "Drops events:", all passing ascending positions to `take`, raising instead of returning an empty log. Causal layer: `case_table(log, treatment, outcome)` encodes one row per case; treatment = an activity name or a case-constant 0/1 column; outcome = "cycle_time"/"n_events" (reserved, collision raises) or a column; `when="anytime"` uses case-start features only (leak-free by construction), `("after_events", k)`/`("after_elapsed", x)` are landmark designs (prefix features at the landmark, already-treated dropped into `n_dropped_treated`, short cases into `n_dropped_short`, estimand population = cases reaching the landmark untreated); named confounders ride along (workload via `open_cases`, calendar on datetime stamps); auto `DomainKnowledge` tiers [covariates] < [treatment] < [outcome] forbid post-treatment adjustment mechanically; zero-variance derived covariates drop silently. `kpi_panel(log, period, unit=, kpis=)` aggregates cases by start-bucket into a `PanelData` (or `TimeSeriesData` when unit=None) for the panel designs; periods are day/week/month on datetimes or a float width on numeric stamps; derived kpi names are reserved. Shared case arithmetic in `process/_cases.py` (case_slices, case_bounds, case_attribute, open_cases, time_seconds). The composed pipeline is the anchor test: complexity world where the naive review gap is 10.8 against a planted 5.0 and case_table -> discover -> estimate lands at 5.05; rollout world where kpi_panel -> did recovers -3.0 within 0.04. PC + tier knowledge returns the mixed face, so the composed route re-faces with `as_kind("dag")` (the guide-06 pattern). Model layer (P3): `ProcessTree` (frozen; leaves = activity or `TAU`, operators seq/xor/par/loop with loop binary (do, redo); xor/par children canonically sorted by alphabet so mined == hand-built structurally; builders `seq/xor/par/loop` coerce strings; `nodes()` gives (path, node) pairs) and `WorkflowNet` (places + labeled-or-silent transitions + weight-one arcs, structural validation in the constructor: disjoint namespaces, bipartite arcs, source/sink degree, every node on a source-to-sink path; `index()` returns the one shared firing rule; `net_of_tree`/`tree.to_net()` is the sound-by-construction conversion) are the contract objects. `discover_model(log, noise=0.0)` is the Inductive Miner from the papers (base cases, then xor/sequence/parallel/loop cuts on the DFG, recursion on projected sublogs, flower `loop(TAU, xor(...))` fall-through; `noise=` is the IMf per-node relative edge filter) returning a `ProcessModel` with provenance (fallthrough paths, `n_filtered_arcs`, `n_dropped_events`); `is_sound(net)` is real classical soundness by capped reachability (raises past the cap; sound nets are bounded); `conformance(log, model)` does token replay (Rozinat sums; documented conventions for unmatched labels and forced firings) and optimal alignments (Dijkstra over the synchronous product, sync/silent free, log/visible-model cost 1, deterministic tie-breaks, per-variant moves; a net that cannot reach its final marking raises pointing at `is_sound`); `decision_points`/`decision_table` read xor splits causally (branch = treatment at the first-event-in-alphabet landmark, covariates strictly pre-landmark reusing `_case_table` helpers, tiers covariates < branch < outcome, default outcome `remaining_time`, ambiguous multi-branch cases dropped with counts, silent-branch splits refused with the alignment-replay reason, unique-leaf-label invariant checked) with a first-class `PositivityReport` (per-branch counts/shares, logistic `overlap_share` for two-way splits, `flagged`); decision anchor: planted -5.0, naive branch gap -3.22, composed decision_table -> discover -> `as_kind("dag")` -> estimate (dml, `treated=`) lands -5.006. All accept `ProcessModel | ProcessTree` (conformance also `WorkflowNet`).

- `ergodic.scm`: a Markovian Bayesian structural causal model, PyMC under the hood (optional, imported inside the methods; the `scm` extra). `SCM(graph, data)` fits one Bayesian `Mechanism` per node, each an explicit-exogenous-noise structural equation (`X_i = f_i(PA_i) + U_i` additive/INVERTIBLE, or a Gumbel-max `g_i(PA_i, U_i)` for binary/categorical), auto-assigned by schema (continuous = Bayesian-linear Gaussian-additive, binary/categorical = Gumbel-max) and overridable by a built-in name or a frozen `Mechanism` instance (the `Learner`/GP/`PyMCLearner`/raw-callable mean overrides are post-MVP). Mechanisms are immutable; the fit factorizes (Markovian + complete data, each node on its own likelihood, sequential by default with a thread-pinned `parallel=True`). Every query carries a posterior and routes through `_compose`, the only caller of `pm.do`/`observe`/`sample_posterior_predictive` (it owns the verified gotcha catalog and a golden-tested RV-naming discipline). The methods: `sample` (observational predictive), `interventional`/`do` (`pm.do` surgery, not conditioning, held to the closed-form back-door gap), and `counterfactual` (the explicit-noise twin network: abduct the unit's noise on the factual graph, predict on the action branch reusing it; exact residual for an invertible mechanism to machine precision; the Gumbel-max categorical counterfactual abducts a truncated Gumbel, and a categorical ancestor re-decides per posterior draw so the interval stays calibrated). `ite(units, X, Y)` reads the per-unit individual treatment effects off that twin network in two framings: an absolute `levels=` contrast `do(X=high)-do(X=low)`, or a `shift=` shock `do(X=x_i+δ)-Y_factual` perturbing each unit from its own factual baseline (the one query that hands the engine a per-unit do-vector, via `_cf_do_column`); constant across units for a linear-additive mechanism (the noise cancels, so it equals the coefficient), genuinely heterogeneous for a binary/categorical outcome (the per-unit counterfactual flip varies with baseline), returning a per-unit numpy array (the structural-model sibling of the inference pillar's conditional-average `cate`). Binary and categorical nodes are first-class in the generative view, so interventions, sampling, and `ate` work for any node type, binary-treatment ATE included (held to `estimate_effect` and the planted truth). `ate(X, Y)` is the honesty layer: it routes through `identify_effect` first and the return type names the world. Back-door adjustment (or the no-path `"null"` case) gives a posterior `SCMResult` contrast; not identified gives a `Sensitivity` (the analytic `b(c) = (cov - c)/var(X)` curve over the assumed confounding, with no scalar accessor, so a naked point is impossible); The SCM also accepts a latent-confounded ADMG (one explicit latent per `<->` edge; the confounded district fit jointly with a sign gauge, non-centered, high `target_accept`), so an effect identified despite the confounding computes from the fitted object: front-door computes (the latent absorbs the confounding, held to the planted truth), while instruments and the general ID functional still raise and point at `estimate_effect` (the latent fit does not impose the exclusion restriction). `engine="dml"` is a post-MVP stub. Anchors: the confounded fork's interventional slope severs the back-door, the counterfactual matches `y + b(x'-x)` to machine precision, a bow returns a `Sensitivity` band bracketing the truth, binary-treatment ATE recovers the planted effect against `estimate_effect`, and a front-door world computes ~1.2 through the latent district where the MVP plug-in raised.

- `ergodic.forecast`: the forecasting pillar, v1 built (S1 to S5; the design is the analysis doc's sections 6 and 8, the sprints are `plans/2026-08-05-forecast-s*.md`). `forecast(data, horizon, *, graph=None, mechanisms=None, reconcile=None, scenario=None, fit="auto", robust=False, draws=1000, warmup=500, chains=1, seed=0, target_accept=0.99)` is the facade: a typed `TimeSeriesData`/`HierarchicalTSData` in, a frozen `ForecastResult` out (per-node `(S, H)` draws, `median`/`mean`/`interval`/`draws`/`to_frame`, `start`/`index` labels, and provenance: mechanisms, graph, schedule, `FitStrategy`, `fits`, `views`, diagnostics, reconciliation, `coherent`, `residual_var`). A `TemporalMechanism` is one node's structural equation through time, the `scm.Mechanism` sibling with explicit noise: `StructuralMechanism` (the workhorse, `mu = (trend + reg + season) * season_factor`, damped LLT + monthly-softmax or Fourier season + one `beta_{base}` per graph parent), `CausalOU` (drivers move the long-run attractor, `kappa` reversion, so the transient answers "when"), `Bass` (diffusion, `p`/`q`/`M`; `q_prior=(2,5)` deviates from the plan because `(2,50)` doubles M on a truncated curve), `ScenarioMechanism` (resolved, never fitted). `assign_mechanisms` dispatches on the schema with `infer_period` reading the index (monthly 12, quarterly 4, weekly 52, else none); counts and categories raise at a named seam. Engine: PyMC with an EXPLICIT `nuts_sampler="numpyro"` (PyMC 6 defaults to nutpie, measured 3.8x slower) and `target_accept=0.99`; the fit model is built at `horizon=0` and the forecast is a SECOND model at `T+H` into which the posterior is replayed by name, with `_audit_sites` enforcing four rules before every ppc (a replayed site must be in the trace at the same shape, a missing site must be `_fc`, an `_fc` site must not be in the trace unless the caller injected it, and NO deterministic of the forecast model may be in the trace: PyMC reads a stored deterministic back from the trace rather than recomputing it, which is why deterministics exist only in forecast models). The naming contract is load-bearing (`{node}_{site}`: `phi`, `sigma_level`, `sigma_slope`, `sigma_obs`, `level0`, `slope0`, `z_level`, `z_slope`, `season_raw`/`fourier`, `beta_{base}`, `kappa`, `mu0`, `p`/`q`/`M`, `nu_raw`, `obs`; forecast-only `z_level_fc`, `z_slope_fc`, `{base}_fc`, `y_fc`; deterministics `mu`, `trend`, `season`, `season_factor`, `reg`, `reg_{base}`, `attractor`, `cumulative`). Three fit paths: independent (no graph), staged (walk the `TrainingSchedule` waves, inject each parent's whole forecast posterior into a copy of the child's trace as `{base}_fc` so nothing collapses to a point), and joint (one model over every node, upstream mean paths feeding downstream regressions, so cross-node correlation survives); `fit="auto"` is joint at or under `AUTO_JOINT_MAX_NODES = 4` modelled nodes, staged above, and `schedule(...)` shows the plan that will run. Reconciliation is per-draw numpy and costs no refit: `bottom_up`, `top_down` (historical or per-draw forecast proportions), `middle_out(level)`, `mint` (diagonal posterior-variance weights or `mint_shrink` off `residual_var`, `trust={node: w}` multiplying precision), `none`; coherence is judged RELATIVE to each parent's own size (an absolute 1e-8 is wrong above a series level of ~5e7). `scenario=` pins a known future (array, scalar, or `"hold"`) and says it makes no causal claim; a scenario key on a node with graph parents raises and names the coming `do=`, which waits for identification on window graphs. `backtest(model, data, ...)` is the universal harness for anything satisfying `ForecastModel` (fit a prefix, forecast a horizon): `Naive`/`SeasonalNaive`/`Drift` baselines, fifteen metrics including MASE and CRPS, expanding cutoffs counted backwards so the freshest origin never truncates, per-fold seeds (fit `seed + i`, forecast `seed + 1000 + i`) and `FoldDiagnostics` (worst divergence share, smallest ESS, worst node) aggregated per fold; `forecast_model(**options)` wraps the facade as a backtestable model and refuses an option the facade lacks. `ForecastResult.explain(windows=, nodes=, method="sequential"|"loo", reduce="sum"|"mean")` returns an `Attribution` of `NodeAttribution` records: a baseline bar, a seasonality bar, one bar per driver (and an `Interaction` bar under `loo`), each a `FactorContribution` carrying per-draw contributions with `credible_interval`, plus `total`, `forecast_total` (what the result's draws say, so reconciliation and observation noise stay visible) and `closure_error` reported always. Two engines: structural (primary, no sampling) recomposes through the mechanism's own `factors()`/`compose()` contract with exact identity elements (a zeroed softmax season is exactly 1), measured against the model's recorded `mu` so a composition that drifted from `build` shows up as closure error; replay (fallback for a custom mechanism) zeroes `{node}_beta_{base}`/`{node}_season_raw` in a trace copy via `zero_sites` and re-forecasts on the stored `ReplayRecipe` seed, so the fresh innovations cancel in the difference. A `Window(label, start, end)` slices the horizon by position or by date on `result.index`. Honesty carried in the docs: posterior intervals under-cover on hard worlds (the S0 sweep measured 74-78% against a nominal 90% where level innovations swamp the slope), so backtest-calibrate rather than trusting the posterior; `phi` recovers systematically low, which flattens a long extrapolation in the conservative direction; staged drops cross-node correlation except through the handoff; and `import ergodic.forecast as mod` binds the FUNCTION, the one shadowed name in the package. Anchors: bars close at 2.3e-16 relative on the structural path and replay agrees with it to 0.06% on the same world and seed, a seasonless world's season bar is 0.04% of the total while an additive world's interaction is exactly zero and a multiplicative one's is 1.8%, and a backtest table has the true spec at CRPS 3.75 and MASE 0.885 against a wrong spec's 16.49 and SeasonalNaive's 4.83.

These re-export from the top level: `from ergodic import dag, admg, DomainKnowledge, identify_effect, tabular, estimate_effect, discover, did, event_study, synthetic_control, interrupted_time_series, granger, case_table, kpi_panel, process_map, discover_model, conformance, decision_points, decision_table, SCM, forecast, backtest`.

## Design decisions to keep

- Full graph surface from day one (marks model), algorithms added in phases.
- Immutable value objects everywhere (graphs and knowledge).
- Hard domain knowledge for the searches. Soft knowledge (`confidence=`) is read by the edge-probability decoders and by `log_prior`/`energy`; the searches still read hard constraints only.
- networkx only at the interop boundary in `graph/_io.py`. The algorithms are native.
- Graph posteriors are method posteriors (API-152, DEC-082): `graph_posterior` reads edge probabilities (pair log score plus the knowledge's `log_prior`) or a decomposable score (BGe, BDeu exact; the BIC family approximate) and returns `GraphSamples`; exact by enumeration (up to 4 variables, 5 for a score) or by the subset sink-set recursion for pair-factorized targets (up to `max_exact` = 15), structure MCMC otherwise. `evaluate_graph` reads DAG/CPDAG/PAG/MAG/ADMG candidates against it. The numbers are "posterior probability under the method" (`PROBABILITY_TERM` in `discovery/_posterior.py` and the note on `evaluate-a-graph.md`); the calibration gate may rename them method scores.
- Data enters as a typed `Dataset`. The dataframe library lives only at `data/_frame.py` (pandas native, polars and arrow via `to_pandas`; narwhals deferred). The two axes, row shape and column schema, stay separate.
- Estimation factors into a `CausalEstimator` (the strategy) and a `Learner` (the sklearn estimator surface, native by default, sklearn/xgboost optional). The result is distribution-shaped: a point now, posterior draws later through the same `EffectEstimate`.
- Categorical encoding belongs to the algorithm wrapper, not the data layer. `data.matrix()` stays integer codes; estimation one-hots in its own design builder (`_covariate_matrix`); a discovery conditional-independence test owns its strategy, one-hot or natively categorical.
